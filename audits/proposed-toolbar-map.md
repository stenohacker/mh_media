# Proposed toolbar — with the new changes

For review only. The builder has not been changed.

Read DOWN each column to see that toolbar row’s left-to-right order. Each numbered position is one button space. “↳ continuation” reserves the second space of a text field or slider. “▾” opens a panel/menu. Dashes are unused space, not blank buttons.

**Highlight and Underline apply only to explicitly selected words. With no words selected, they are disabled.**

Exactly three toolbar rows, with horizontal scrolling. All text fields and sliders occupy two button spaces, including those inside panels.

## Panels

| Button | Contents |
|---|---|
| Add text | Regular, italic, bold, handwriting, Impact Label, reversed Impact Label; retain existing whole-text underline creation option here |
| Circle / square | Dotted outline, solid outline, filled, filled with solid border, filled with dotted/dashed border |
| Selected text / fill color | Swatches and custom picker for selected words, selected text, circle/square fill, or solid cover fill; objects retain independent colors |
| Line / border color | Swatches and custom picker for lines, arrows, circle/square borders, and magnifier border; magnifier outline on/off |
| Highlight selected words | Color and Remove highlight; square corners, no extra horizontal padding; exclude trailing whitespace |
| Underline selected words | Apply/remove, straight or hand-drawn, independent color, thickness, and offset |
| Corner presets | Existing presets, alongside the two-space rounding slider |
| More draft options | Save Editable Backup, Rename Draft, Reset Draft |

Save status stays within the current-draft area. Floating panels do not create a fourth toolbar row. Intro “Body left” remains on the card. Shapes-menu images have no color controls.

## Consolidation included in this proposal

- Word/text/object/fill/cover color buttons → shared Selected text / fill color.
- Hotspot and text/card alignment → shared text alignment.
- Corner more/less → presets and rounding slider.
- Markup weight buttons → shared border thickness slider, extended to magnifier borders.
- Transparency and blur-strength pairs → respective sliders.
- Repeated image replacement actions → Replace slide image / GIF, including scrolling slides.
- Text-creation buttons → Add text menu.

The two layer buttons are labeled “to back” and “to front” here to match the current builder actions precisely.
